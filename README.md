# Maimemo Companion

一款运行在 macOS 上的单词伴学侧栏。它是独立应用，不注入或修改墨墨；跟随墨墨背单词的当前词，在你需要时提供 AI 辅助理解和记忆，不替代原有的背词计划与复习流程。

目前是持续测试中的个人项目，仅适配 Mac 上的墨墨背单词。

## 为什么做

背单词时，最重要的几秒钟是**先自己回忆**。如果解释和一大串中文释义立刻出现，反而容易打断判断；但碰到一词多义、语境变化或总记不住的词，又需要一个能在原界面旁提供解释的帮手。

这个项目把辅助理解放在背词软件旁边：墨墨负责呈现单词和安排复习，Companion 只读识别当前词，再按你的操作给出线索。希望记住的不是堆叠的译词，而是一个可迁移的核心概念，以及它进入不同句子后怎样形成具体意思。

## 背词时怎么用

1. 在 Mac 上打开墨墨和 Maimemo Companion，让墨墨保持非全屏；右侧有足够空间时，侧栏会贴着墨墨窗口并跟随其高度。
2. 新词出现时先自行回忆。侧栏默认只显示英文词，不提前展示释义。
3. 需要帮助再点「给我线索」：已有本地卡片先显示一个核心概念和一个语境；「换个说法」每次只显示一条额外线索，「深入理解」才展开其他义项、记法和反馈。
4. 若这个词还没有卡片，需要再次主动点「生成一条线索」才会请求模型。模型地址、名称和 API Key 可在右上角「设置」中填写。

没有配置模型也能跟随当前词；不会自动调用 AI 或编造生成结果。当前提供的是按词生成的记忆提示，**还不是自由提问式聊天**。

## 设计取向

- **回忆优先**：每次切词都重新隐藏答案，已缓存的卡片也不例外。
- **由少到多**：先抓核心概念，再按需查看语境、画面和联想，避免小侧栏一次塞满信息。
- **记住自己的卡点**：反馈按单词、词性和义项分别保存；一种记法不管用，可以换方法，旧版本仍保留。
- **伴随而不接管**：通过 macOS 辅助功能只读获取墨墨窗口和当前词，不点击、写回或控制墨墨，也不依赖墨墨官方 API。

## 技术与数据边界

项目使用 **Swift** 开发：SwiftUI 构建侧栏界面，AppKit 管理 macOS 窗口，Accessibility（`AXUIElement`）读取当前词；记忆模块调用用户配置的 OpenAI 兼容聊天补全接口。

模型只在你主动生成或重做记法时调用。请求会向你配置的模型服务发送当前词、你填写的卡点，以及相关的旧记法、遗忘原因和已有卡片摘要；API Key 仅存于 macOS 钥匙串，记忆卡与反馈保存在本机应用支持目录，不进入 Git 仓库。当前没有 OCR、剪贴板监听或对其他背词软件的适配。

## 从源码构建

需要 macOS 13+、Swift 命令行工具，以及你自己的稳定代码签名身份。本仓库不包含证书，也没有可供其他 Mac 直接安装的通用签名包；更换签名或安装路径后，macOS 可能要求重新授予辅助功能权限。

```sh
MAIMEMO_SIGNING_IDENTITY="你的代码签名身份" ./scripts/build-app.sh
open "build/Maimemo Companion.app"
```

首次运行，在「系统设置 → 隐私与安全性 → 辅助功能」中允许 Maimemo Companion 读取界面。构建脚本会先签名并验证，再替换本机应用。

具体的实测范围和未验证事项见 [验证记录](./MEMORY_VALIDATION.md)；开发过程中的读取探针和技术证据见 [技术验证](./VALIDATION.md)。
