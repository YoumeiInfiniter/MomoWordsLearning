# 📖 Maimemo Companion

在背词软件旁边，给单词搭一座通往记忆的小桥。

> 先自己想一想，需要时再给一条线索。

Maimemo Companion 是一款原生 macOS AI 伴学侧栏，目前适配 Mac 上的墨墨背单词。它安静地待在学习窗口右侧，跟随你正在背的词：用一句谐音联想或一幅字母插画帮你抓住意思，再用一个短句把意思放回语境。

它是独立应用，不是墨墨官方插件。原来的背词计划不变，只在你需要的时候，递上一点帮助。

当前主分支已包含 V2，版本为 **0.3.4**，仍在个人使用和持续测试中。

## 💡 为什么做

这个项目来自背词时两种很熟悉的感觉：

- 「中文释义看着都懂，可只看到英文，脑子里又空了。」
- 「这个意思我背过，为什么放进这个句子就认不出来？」

所以，重点不是再堆一页词典，而是补上两层联系：先让词形或声音勾起一个意思，再理解这个意思怎样落到具体语境里。

**单词 → 记忆联想 → 核心意思 → 句中含义**

墨墨继续负责单词、释义和复习安排，Companion 补上「怎么联想、怎么理解」这一小段。每次切词先把线索藏起来，给你自己回忆的时间；点开后，也只留一个主要联想、一句核心意思和一个英文短句，不让小侧栏变成另一份背词任务。

## 🧠 给记忆找一个落脚点

- 🔊 **谐音联想 · 给声音挂一个钩子**：用与读音大致相近的中文短句，把声音和意思连起来。新词默认使用这种方式；谐音只是辅助记忆，不冒充标准发音或词源，没有自然谐音时不硬编。
- 🎨 **字母插画 · 让字母长成一幅画**：把英文词的字母按原顺序融入表达意思的画面，并配上简短解释。由你手动选择；选择后会直接准备提示词并生图，不需要第二次确认。

每次只展示一种记法。已经准备好的两种联想可以切换，卡片和图片保存在本机。下次碰到这个词，先回忆、再点开，就能拿回之前的联想。

谐音不合适？在下方写一句原因（也可以留空），点「换个联想」再试一次。模型会参考上一条联想和这次反馈，不满意可以继续换；每次主动点击会发起一次模型请求。新卡片通过校验后才替换，失败保留原卡，旧卡与修改原因留存在本机记录中，已有插画不会因此重新生成。

> 费用提醒：谐音同样会产生模型用量费用；插画另有图片生成费用，首次生成和手动重试都可能扣费。已有缓存优先复用。

## 👋 开始一起背词

1. 打开墨墨和 Companion，在「系统设置 → 隐私与安全性 → 辅助功能」中授权 Companion。
2. 在侧栏右上角的「设置」填写记忆模型地址、名称和 Key；想用插画时，再填写独立的图片生成 Key。
3. 让墨墨保持非全屏，右侧留出空间。侧栏会贴着墨墨右侧，跟随其可见窗口高度；空间不足时不会强行挤动墨墨。
4. 看到新词，先给自己几秒钟：「我记得它吗？」需要帮助时轻触侧栏学习区域。已有卡片直接显示；没有卡片时开始生成，完整的首条联想先展示，其余内容继续补全。
5. 默认看谐音，需要画面时再选「字母插画」。设置、权限和连接诊断都放在设置页，不占学习页的注意力。

捕获单词、切词和启动应用本身不会自动请求 AI。生成时切到其他词，旧结果不会显示到新词上；主动为新词生成时会取消旧请求，但服务商可能已产生部分费用。

## ⚡ 快一点，还是多想一会儿

当前使用过的记忆模型配置：

- 完整接口地址：`https://api.deepseek.com/chat/completions`
- 模型名称：`deepseek-flash`
- API Key：在设置页自行填写。

在设置中，用「开启思考模式」选择这次的节奏：默认开启，让模型先思考再输出；关闭后直接生成，可以比较更快的响应体验。开关自动保存，下次生成生效，不会重发进行中的请求或重做缓存卡片。这个开关目前仅适用于 DeepSeek 官方接口。

记忆模型接入采用 OpenAI 兼容聊天补全格式，需要服务支持 JSON 输出模式。图片服务当前接入 MaiziAI 文生图，使用 `gpt-image-2.5`，每次生成一张 1K 方图；不需要图片服务也可以只用谐音。

生成请求使用 JSON 输出约束和本地结构校验；可明确恢复的格式问题在本地处理，不自动追加模型修复请求或反复重试。速度和质量会随模型、网络及单词变化，不保证固定秒数；实际验证范围见 [验证记录](./MEMORY_VALIDATION.md)。

## 🧩 里面是怎么工作的

项目使用 Swift 开发：SwiftUI 构建界面，AppKit 管理窗口，macOS Accessibility 只读识别墨墨当前词。界面采用原生玻璃材质，中文使用宋体，英文使用衬线排版。

- `Sources/MaimemoCompanionApp/`：学习侧栏、设置、生成状态和窗口停靠。
- `Sources/MaimemoAXCore/`：当前词识别与辅助功能读取。
- `Sources/WordMemoryCore/`：教学提示词、JSON 契约、模型与图片接口、本地缓存。
- `Sources/WordMemoryCheck/`：离线请求、解析、旧卡兼容和存储检查。

API Key 仅存于本机 macOS 钥匙串。卡片、学习记录和图片保存在本机应用支持目录，不进入 Git；生成时会把当前词和相关学习内容发送到你配置的模型服务，插画提示词会发送到图片服务。

当前不读取墨墨账号或调用墨墨官方 API，也不注入、修改或控制墨墨。没有 OCR、剪贴板监听、自由聊天或对百词斩等其他应用的适配。只读识别依赖墨墨当前的辅助功能树，不代表对所有版本都能永久兼容；AI 联想和图片也可能有错误，需要自行判断。

## 🛠️ 从源码构建

需要 macOS 13+、支持 Swift 6 的命令行工具，以及自己的稳定代码签名身份。本仓库不包含证书，当前没有面向其他 Mac 的通用签名安装包；更换签名或安装路径可能需要重新授权辅助功能。

```sh
MAIMEMO_SIGNING_IDENTITY="你的代码签名身份" ./scripts/build-app.sh
open "build/Maimemo Companion.app"
```

构建脚本会先构建、签名和验证，再替换本机应用。第二版设计与后续验证见 [V2 说明](./V2_WORD_LINK.md)；读取层的历史技术证据见 [技术验证](./VALIDATION.md)。
